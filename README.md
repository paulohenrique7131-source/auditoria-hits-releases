# Auditoria HITS — Releases

Downloads da extensão de auditoria do HITS PMS.

**Baixar a versão mais recente:** https://github.com/paulohenrique7131-source/auditoria-hits-releases/releases/latest

## Instalar
1. Baixe o `.zip` do release mais recente e extraia numa pasta fixa.
2. `chrome://extensions` (ou `edge://extensions`) → **Modo do desenvolvedor**.
3. **Carregar sem compactação** → selecione a pasta extraída.
4. Em ⚙ Configurações da extensão, cole o token do GitHub e Salvar.

O código-fonte fica em repositório privado separado.
